## 做了什么，为什么

Day01 已从旧重放里验证了「全部、部分、零个」的统计定义。今天在两个未重放过的捕获上跑通完整流程，检查新脚本能否从原始框、分数和类别得到同样的输出，再把整个图的候选决定映射回每个丢失目标。试跑按队列顺序选图，方便复查选择过程。

| 模型/图片 | 原 NMS 输入 | 原与重放均保留 | 归因通过的丢失目标 |
|---|---:|---:|---:|
| IR/`030052` | 123 | 17 | 3 |
| Fusion/`030027` | 52 | 3 | 1 |

两项均无分数并列或临界 IoU 歧义。对重放实际比较的框，再用 CPU float32 张量计算核对预测框重叠值。这里保留原阈值和原候选。

## 怎么理解结果

| 模型/图片 | 目标 | 整图最高分框直接移除 / 原达标框 | 分类 |
|---|---|---:|---|
| IR/`030052` | G0 | 3 / 4 | 部分 |
| IR/`030052` | G3 | 0 / 1 | 零个 |
| IR/`030052` | G4 | 0 / 4 | 零个 |
| Fusion/`030027` | G1 | 0 / 2 | 零个 |

例如 IR `030052` 的 G0，最高分框 `3477` 先移除了三个达标框，第四个 `10062` 是由后续保留框 `9447` 移除的。Fusion `030027` 的 G1 的两个达标框都由 `1026` 首次移除，和整图最高分框 `1286` 的直接归因计数是零。这样可以区分首轮最高分的作用和其余保留框在后续轮次的作用。
