# Week11 Day06 · 全验证集 RoI 阶段统计

读取 300 份模型×图片捕获，IR 和 Fusion 共享同一批 416 个标注目标。以下是目标级几何覆盖，候选与该目标的 IoU ≥ 0.75 时计为达标。

| 阶段 | IR 覆盖数 | Fusion 覆盖数 |
|---|---:|---:|
| RPN 输出 | 302 | 285 |
| RoI 回归解码 | 323 | 326 |
| 裁剪 | 323 | 326 |
| 去背景展开 | 323 | 326 |
| 分数筛选后 | 322 | 324 |
| NMS 前 | 322 | 324 |
| NMS 后 | 225 | 200 |
| 100 框预算后 | 225 | 200 |
| 最终输出 | 225 | 200 |

回归解码时首次达标，IR **54** 个，Fusion **60** 个。同一阶段也可能使原先达标的框掉出阈值，阶段表分别记录得失。

类别 NMS 在各自进入 NMS 前已覆盖的目标中，IR 丢失 **97/322**，Fusion 丢失 **124/324**。

只比较 NMS 前两模型都覆盖的 **297** 个目标，两者都保住 167 个，仅 IR 丢 25 个，仅 Fusion 丢 50 个，两者都丢 55 个。

最高分类分数以整张图的 NMS 前候选为范围，逐目标记录该候选与标注的 IoU 及实际去留。在多人图里，最高分框可以属于另一人。保存高分框与丢失覆盖同时出现的情况，具体抑制关系仍需单独核验。

本轮只加载原始候选捕获并计算 IoU，新增模型前向、权重加载和独立 NMS 重放均为 0。
